What this is

Track Record takes fun questions about music, the stuff you'd argue about in a group chat, and answers them with real, public data instead of vibes. Every post follows the same format:

The format

  1. The hook — a surprising claim or question.
  2. The visual — the shareable chart.
  3. The dataset — named and sourced, always public and free to reuse.
  4. The method — exactly how the chart was built, in plain English.
  5. The takeaway — what it means, and what it doesn't.

Who's behind it

Track Record is run by Longo, a data analyst and mom building small independent projects under Longo Co. LLC. This one's for anyone who likes music and likes seeing the receipts.

On the data

Sources are always named and linked. When a post uses a sample rather than a full dataset (for speed, or because a file is huge), that's disclosed in the Method section. The underlying datasets and the code behind every chart aren't hosted on the site itself, but they're all public in the Track Record GitHub repo if you want to dig further or check the work yourself.
